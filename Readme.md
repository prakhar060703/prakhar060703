## 🔬 Research — Long-Term Memory for Egocentric Video

**MTP Topic:** *Long-Term Memory Integration with Procedural Reasoning for Egocentric Videos*

Working on the [EgoLife dataset](https://huggingface.co/datasets/lmms-lab/EgoLife) — multi-day first-person video captured continuously — to build systems that can answer long-range episodic memory questions.

**Core technical areas:**

- **Caption-based memory** — dense captioning of ego-video into timestamped JSON entries; used as a long-term memory store (~6K captions over 7 days)
- **Embedding retrieval** — BGE text embeddings + ChromaDB for semantic search over caption pools; query-time retrieval constrained to evidence before the question timestamp
- **VideoTree-style reasoning** — adaptive breadth + depth expansion over retrieved caption clusters; leaf captions fed as evidence to an LLM for multi-choice QA
- **Multimodal pipeline (FIO)** — Feature-Interaction-Object records stored in ChromaDB; question decomposed via Qwen, FIO evidence retrieved, matched to video clips; EVA-CLIP frame features + InstructBLIP captioning + Qwen2.5-7B final answer
- **Benchmark construction** — built TASHA QA set (150 verified questions, 5 reasoning categories: EntityLog, EventRecall, HabitInsight, RelationMap, TaskMaster) mirroring the JAKE benchmark format
- **Temporal gap analysis** — split 500-question JAKE benchmark by evidence-query temporal distance (<2h, 2-6h, 6-24h, >24h) to study how retrieval degrades over time
- **Abstention-aware evaluation** — compared hallucination-allowing vs evidence-constrained LLM settings; studied trade-off between coverage and faithfulness

**Models used:** `Qwen/Qwen2.5-7B-Instruct`, `EVA-CLIP`, `InstructBLIP`, `BGE text embeddings`
**Infrastructure:** SLURM HPC cluster, NVIDIA A40 / H100 / V100 GPUs
